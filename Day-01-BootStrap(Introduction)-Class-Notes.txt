BOOTSTRAP
---------
* Bootstrap is a powerful front-end framework used for creating : 
	
	1. responsive websites
	2. mobile-friendly applications
	3. modern user interfaces
	4. enterprise-level dashboards
	5. admin panels
	6. business websites

What is Bootstrap?

* Bootstrap is a collection of : 
	
	1. pre-written CSS classes
	2. JavaScript components
	3. responsive layout utilities

* Using Bootstrap, developers do not need to write large amount of CSS manually.

* Instead of creating everything from scratch, Bootstrap provides ready-made classes.

Example : 

* Instead of writing : 

	color : blue;
	margin-top : 20px;
	padding : 10px;

* we simply use Bootstrap classes like : text-primary mt-3 p-2

* This reduces : 
		
	1. development time
	2. CSS complexity
	3. maintenance effort

Who Developed Bootstrap?

* Bootstrap was originally developed by : Twitter

* Now it is maintained as an open-source framework and widely used globally.

Why Bootstrap Created?

* Before Bootstrap, developers faced many UI problems : 
	
	1. browser compatibility issues
	2. responsive design difficulties
	3. repeated CSS writing
	4. inconsistent layouts
	5. slow UI development

* Every developer wrote their CSS differently.

* This created : 
	
	1. maintenance problems
	2. inconsistent design
	3. longer development cycles

* Bootstrap solved these problems by providing : Standardized UI framework.

What is Front-End Framework?

* A front-end framework is a ready-made UI toolkit containing : 
	
	1. layout systems
	2. buttons
	3. forms
	4. cards
	5. navigation bars
	6. tables
	7. modals
	8. responsive utilities

* Instead of designing everything manually, developers reuse framework components.

Features of Bootstrap
----------------------
* Bootstrap contains many powerful fearures.

	1. Responsive Design : It automatically adjusts UI based on screen size.
	
	2. Mobile First Approach : Design starts for mobile screens first, then expands for larger screens.
	
	3. Ready-Made Components
		
		Provide : buttons, cards, navbar, carousel, modals, alerts.
	
	4. Grid System : It Creates responsive layouts using rows and columns.
	
	5. Faster Development : It Reduces manual CSS writing.
	
	6. Browser Compatibility : It Works consistently across browsers.
	
What is Mobile-First Approach?

* Bootstrap follows : Mobile-First Design

* Meaning : UI designed first for smaller screens.

* Then enhanced for : tablets, laptops, desktops

Why Mobile-First Important?

* Now a days most users access applications from : smartphones.

Example : shopping apps, banking apps, food delivery apps, social media.

Two Methods To Install Bootstrap
---------------------------------
* Bootstrap can be added using : 
	
	1. CDN
	2. Local Files

1. Method 1 : CDN (Recommended for Beginers)

* CDN means : Content Delivery Network

* Instead of downloading Bootstrap, we use online links.

* Browser downloads Bootstrap files from internet.

Advantages of CDN
------------------
1. easy setup
2. faster implementation
3. no manual downloads
4. globally optimized servers.

Method 2 : Local Files

* In this method developers download Bootstrap files manually.

* Then project links local CSS and JS files.

* Mostly used in :
	
	1. enterprise internal systems
	2. offline applications

Example 1 : Full Bootstrap Installation Setup

<!DOCTYPE html>
<html lang="en">

<body>

  <div class="container mt-4">
    <h1 class="text-primary">
      Bootstrap Started
    </h1>
    <p>
      This is a Bootstrap example.
    </p>
  </div>

  <!-- Bootstrap JS -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"

</html>

Complete Real-Time Flow : Browser Loads HTML -> Bootstrap CSS Downloaded -> Bootstrap Classes Become Available -> HTML Elements Styled Automatically -> Responsive Layout Generated.

Interview Questions
-------------------
1. What is Bootstrap?
A. Bootstrap is a front-end framework used for responsive web design.

2. What is CDN?
A. Content Delivery Network used for loading files online.

3. What is mobile-first approach?
A. Designing UI for mobile screens first.

4. Why Bootstrap popular?
A. Because it reduces development time and supports responsive design.

5. Difference between container and container-fluid?
A. 
	1. container : fixed responsive width
	2. container-fluid : full width
	
6. Why Bootstrap JS required?
A. For interactive components like modals and carousel.
