Grid System In Bootstrap
------------------------
* Bootstrap Grid System is a layout system used to arrange web page content into : 1. rows and 2. columns

* Grid System help developers divide web page into sections

Example : 
	
	1. Sidebar
	2. Navbar
	3. Content Area
	4. Cards
	5. Forms
	6. Tables => All positioned using grid layout.

Why Grid System Important?

* Befor Bootstrap Grid System, Developers Used : 
		
	1. float
	2. manual CSS positioning
	3. fixed widths
This created many problems : 
	
	1. responsive issues
	2. alignment problems
	3. mobile compatibility issues
	4. complex CSS maintenance

Bootstrap solved these using : Responsive Grid System

What is Responsive Layout?

* Responsive Layout means, UI automatically adjusts based on screen size

Example : 
	
	1. mobile : single column
	2. tablet : two columns
	3. desktop : four columns

This automatic adjustment is handled using Bootstrap Grid System.

Bootstrap Grid System Based on 12 Columns
------------------------------------------

* Bootstrap Grid System internally divides screen into : 12 columns

* Entire webpage width is 12 units

Example : 
		
	1. col-12 : full width
	2. col-6  : half width
	3. col-4  : 3 columns width
	4. col-3  : quarter width
	
12 Slices

6 + 6 = 12
4 + 4 + 4 = 12
3 + 3 + 3 + 3 = 12

What Happens Internally?

* Bootstrap Internally Calculates : 4 / 12 = 33.33%

* So each column takes  : 33.33% width

* bg-primary : Applies Bootstrap primary backeground color

* text-white : Change text color to white

* p-3 : Adding padding inside column

Responsive Grid Layout
----------------------
* Bootstrap Supports different Screen sizes : 
	
	1. col-sm : Uses Mobile Device
	2. col-md : Uses Tablet Device
	3. col-lg : Uses Laptop Device
	4. col-xl : Uses Desktop Device
	5. col-xxl : Uses Large Desktop Device

Interview Questions
-------------------
1. What is Bootstrap Grid System?
A. Bootstrap Layout system based on rows and columns

2. How many columns Bootstrap grid contains?
A. 12 columns

3. What is row class used for?
A. Creates horizontal layout section.

4. What is col-6?
A. Column occupying 6 out of 12 width.

5. What is responsive design?
A. UI automatically adjusts based on screen size.

6. What are Bootstrap breakpoints?
A. sm, md, lg, xl, xxl

7. What is nested grid?
A. Grid System inside another column.
