Bootstrap Typography
--------------------
* Typography is one of the most important part of web design because every application contains : 
	
	1. headings
	2. paragraphs
	3. labels
	4. titles
	5. descriptions
	6. reports
	7. dashboard text
	8. form content

* If text styling is poor, application looks unprofessional.

* S0 Typography helps developers create : 
	
	1. readable UI
	2. attractive design
	3. proper alignment
	4. professional text structure.
	
What is Typography?

* Typography means : Styling and formatting text

* Typography controls : 
	
	1. font size
	2. font weight
	3. alignment
	4. readability
	5. spacing
	6. appearance

* Bootstrap provide ready-made Typography classes.

Why Typography Important?

* Good Typography improves : 
	
	1. readability
	2. UI appearance
	3. user experience
	4. professional design
	5. content structure

* Bad Typography creates : 
	
	1. confusing UI
	2. poor readability
	3. unprofessional applications

Bootstrap Typography Features
-----------------------------
* Bootstrap provides : 
	
	1. heading styles
	2. display headings
	3. text alignment
	4. font styling
	5. text colors
	6. text transformations
	7. font weights

Normal Headings and Heading Hierarchy
-------------------------------------
* Bootstrap automatically styles : 

h1 : Largest, 
h2 : Large, 
h3 : Medium, 
h4 : Smaller, 
h5 : Small, 
h6 : Smallest

Display Headings
---------------
* Bootstrap provides : display-1 to display-6

* These are much larger than normal headings.

* Used for : 
	
	1. banners
	2. landing pages
	3. main titles
	4. dashboards
	5. hero sections

Difference Between h1 and display-1
-----------------------------------
1. h1 : 
	
	* normal heading
	* Standard size
	* Used in content

2. display-1 : 
	
	* Very large heading
	* Huge title size
	* Used in hero sections

Text Alignment
--------------
* Bootstrap Provides alignment utilities.
	
	1. text-start : Left
	2. text-center : Center
	3. text-end : Right

Why Alignment is Important?

* Alignment improves : 
	
	1. readability
	2. UI structure
	3. professional appearance
