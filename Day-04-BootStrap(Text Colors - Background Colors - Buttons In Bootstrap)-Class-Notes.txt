Bootstrap Text Colors
---------------------
* Colors play a major role in UI design because users understand information visually very quickly.

For Example : 
	
	1. green usually represents success
	2. red represents error or danger
	3. blue represents primary actions
	4. yellow represents warning

* So Colors improve User experience, readability, UI communication and professional appearance.

* In enterprise applications, developers heavily use Bootstrap color classes to create : 
	
	1. alerts
	2. notifications
	3. dashboards
	4. reports
	5. status indicators
	6. messages

What are Text Color Classes?

* Bootstrap provide predefined text color classes.

* Instead of writting custom CSS like : color : red;

* We simply use : class = "text-danger"

Why Bootstrap Colors Important?

* Before Bootstrap, developers manually wrote : hex codes, RGB values, custom CSS classes

Example : color : #ff0000;

This created problems : Inconsistent colors, repeated CSS, difficult maintenance.

Main Bootstrap Text Color Classes
---------------------------------
* Bootstrap provides several standard color utilities.

	1. text-primary : Primary Color -> blue
		
		Used for : main headings, links, important UI sections
	
	2. text-secondary : Secondary gray Color
		
		Used for : less important content, descriptions, muted text
	
	3. text-success : Green Color 
		
		Used for : success messages, completed operations, positive status
	
	4. text-danger : Red Color
		
		Used for : errors, delete actions, validation failures
	
	5. text-warning : Yellow or Orange Color
		
		Used for : warning messages, caution alerts
	
	6. text-info : Light blue Color
		
		Used for : informational messages, help sections
	
	7. text-dark : Dark black Color
		
		Used for : normal text, readability
	
	8. text-light : Light white Color
		
		Used for : dark backgrounds

Bootstrap Background Colors
---------------------------	
* In Web applications, colors are not applied only to text.

* We also apply colors to : 
	
	1. cards
	2. buttons
	3. alerts
	4. navbar
	5. dashboards
	6. sections
	7. tables
	8. containers

* These background colors improve : 
	
	1. user experience
	2. UI appearance
	3. readability
	4. visual communication

Why Background Colors Important?

* Background Colors help users understand : 
	
	1. different sections
	2. alerts
	3. status messages
	4. priorities
	5. notifications

Example : 
	
	1. red background : danger
	2. green background : success
	3. yellow background : warning

Main Bootstrap Background Color Classes
----------------------------------------
* Bootstrap provides several standard background utilities

	1. bg-primary : Primary background Color : blue
		
		Used for : navbar, primary sections, dashboard headers
	
	2. bg-secondary : Gray background
		
		Used for : secondary sections, less important content
	
	3. bg-success : Green background
		
		Used for : success alerts, completed actions, confirmation messages
	
	4. bg-danger : Red Background
		
		Used for : error alerts, delete warnings, failures
	
	5. bg-warning : Yellow or Orange background
		
		Used for : warnings, pending actions
		
	6. bg-info : Light blue background
		
		Used for : information sections, updates, announcements
		
	7. bg-dark : Dark black background
		
		Used for : navbar, footer, dark themes
		
	8. bg-light : Light white or gray background
		
		Used for : soft UI sections, cards, forms
