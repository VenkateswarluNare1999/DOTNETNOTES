Layout Systems
--------------

* Modern CSS Provides two powerful layout Systems : 
	
	1. Flexbox (Flexible Box Layout)
	2. CSS Grid Layout
	
* These tools help developers align elements, control spacing, and create responsive layout easily.

1. 	Flexbox (Flexible Box Layout)

* Flexbox, also called the Flexible Box Layout Module, is a one-dimensional layout system in CSS used for arranging elements efficiently inside a container.

* It is designed to distribute space dynamically and align items properly even when the size of the elements is unkonwn or changes dynamically.

* Flexbox works mainly in one direction at a time : 
	
	1. either horizontally (row)
	2. or vertically (column)

 This is why Flexbox is called a one-dimensional layout system

* It is best suited for : 
	
	1. navigation bars
	2. button groups
	3. cards in a row
	4. alignment tasks
	5. centering elements
	6. responsive menus
	7. toolbars
	8. UI component alignment

* In Flexbox, there are two important concepts : 
		
	1. Flex Container
	2. Flex Items

* The parent elements becomes a flex container using : display : flex;	

* All direct child elements automatically become flex items.

* Flexbox provides powerful alignment features such as : 

	1. horizontal alignment
	2. vertical alignment
	3. spacing distribution
	4. ordering
	5. wrapping
	6. dynamic resizing

Important Flexbox Terminology
-----------------------------
1. Flex Container : Parent element
2. Flex Items : Child elements
3. Main Axis : Primary direction
4. Cross Axis : Opposite direction
5. justify-content : Align along main axis
6. align-items : Align along cross axis.

Example : Basic Flexbox Row

1. Index.html : 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>FlexBox Examples</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="container">
    <div class="box">Box 1</div>
    <div class="box">Box 2</div>
    <div class="box">Box 3</div>
  </div>
</body>
</html>

2. style.css : 

.container{
    display: flex;
    padding: 20px;
    background-color: lightgray;
}

.box{
    width: 100px;
    height: 100px;
    background-color: royalblue;
    color: white;
    margin: 10px;
}

Real-Time Usage Case
--------------------
* This layout is commonly used in : 

	1. navigation menus
	2. horizontal cards layouts
	3. product listings
	4. toolbar sections
	5. dashboard rows
	
Example 2 : Centering Using Flexbox

1. Index.html : 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>FlexBox Examples</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="center-container">
    <div class="item">Center Box</div>    
  </div>
</body>
</html>

2. style.css : 

.center-container{
    display: flex;

    justify-content: center;
    align-items: center;

    height: 300px;
    background-color: lightblue;
}

.item{
    width: 150px;
    height: 150px;
    background-color: darkblue;
    color: white;

    display: flex;
    justify-content: center;
    align-items: center;
}

	2. positioning
	3. line-height hacks
	4. table layouts

* Flexbox solved this problem elegantly.

Real-Time Usage Case 
--------------------
* Used in :

	4. hero sections
	5. dashboard cards

Important Flexbox Properties
----------------------------
1. display : flex -> Creates flex container
2. flex-direction -> Row or column layout
3. justify-content -> Main axis alignment
4. align-items -> Cross axis alignment
5. flex-wrap -> Allows wrapping
6. gap -> Space between items

2. CSS Grid Layout

* CSS Grid Layout is a two-dimensional layout system used for creating complex web layouts using rows and columns simultaneously.

* CSS Grid is considered one of the most powerful layout systems in modern frontend development.

* It allows to create : 

	1. dashboard layouts
	2. responsive galleries
	3. complex website structures
	4. magazine layouts
	5. admin panels
	6. product grids
	7. advanced responsive systems

* In CSS Grid : 
	
	1. parent element becomes grid container
	2. child element becomes grid items

* Grid allows developers to define : 
	
	1. rows
	2. columns
	3. gaps
	4. item placement
	5. spanning behaviour
	6. responsive structures

* Modern frontend frameworks and enterprise UI applications use Grid extensively for : 
		
	1. dashboards
	2. analytics panels
	3. reporting systems
	4. responsive cards
	5. enterprise applications

Important Grid Terminology
--------------------------
1. Grid Container : Parent element
2. Grid Item : Child element
3. Grid Row : Horizontal track
4. Grid Column : Vertical track
5. Grid Gap : Space between cells

Example 1 : Basic Grid Layout

1. Index.html : 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS Grid Examples</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="grid-container">
    <div class="grid-item">Item 1</div>
    <div class="grid-item">Item 2</div>
    <div class="grid-item">Item 3</div>
    <div class="grid-item">Item 4</div>
  </div>
</body>
</html>

2. style.css : 

.grid-container{
    display: grid;

    grid-template-columns: 200px 200px;
    gap: 20px;

    background-color: lightgray;
    padding: 20px;
}

.grid-item{
    background-color: royalblue;
    color: white;
    padding: 40px;
}

Real-Time Usage Case 
---------------------
* Used in : 

	1. product galleries
	2. dashboard cards
	3. admin panels
	4. photo galleries
	5. analytics systems

Example 2 : Responsive Grid Using repeat()

    padding: 50px;
}

Difference Between Flexbox vs Grid
----------------------------------
1. Flexbox : 

	* one-dimensional
	* Row or Column
	* Best for alignment
	* Simpler layouts
	* Component alignment

2. Grid : 
	
	* Two-dimensional
	* Rows and Columns
	* Best for page layouts
	* Complex layouts
	* Full page structures

When to use Flexbox 
------------------
* USe Flexbox for : 
	
	1. navigation bars
	2. button groups
	3. menus
	4. centering
	5. small UI components

When to use Grid
----------------
* Use Grid for : 
	
	1.complete page layouts
	2. dashboards
	3. galleries
	4. admin panels
	5. responsive sections
	6. complex structures

Flexbox is best for : 
		
	1. alignment
	2. spacing
	3. one-dimensional layouts

Grid is best for : 
	
	1. structured layouts
	2. rows and columns
	3. complete page architecture.
