Bootstrap Alerts
----------------
* Alerts are used to display messages to users.

Example : 

1. Login Successful
2. Payment Failed
3. Employee Added
4. Warning Message
5. Invalid Password
6. Server Error

What is an Alert?

* An alert is a Bootstrap component used to show : 
	
	1. success messages
	2. warning messages
	3. error messages
	4. informational messages

* Alerts help users understand : 
	
	1. what happend
	2. wheather action succeeded
	3. wheather something failed

Why Alerts Important?

* Without alerts users won't know : 
	
	1. action completed or not
	2. errors occured or not.

* Alerts improve : 
	
	1. communication
	2. usability
	3. user experience

Bootstrap Alert Classes
-----------------------
* Bootstrap provides several alert types 

	1. alert-primary : Primary informational alert
	2. alert-success : Success alert, Usually green
	3. alert-danger : Danger / error alert, Usually red.
	4. alert-warning : Warning alert, Usually yellow
	5. alert-info : Information alert, Usually blue / light blue
	
Basic Alert Structure
---------------------
* Bootstrap alerts require : alert class and modifier class

Example : <div class="alert alert-success">Employee Added Successfully</div>

Why Enterprise Applications Use Alerts?

* Because alerts provide : 
	
	1. instant communication
	2. better user experience
	3. proper feedback
	4. professional UI behaviour

Bootstrap Cards
---------------
* Cards are one of the most commonly used UI components in modern web applications because they help developers organize information in a clean, professional, and structured format.

* In real-time applications, cards are used for displaying : 
	
	1. products
	2. employee profiles
	3. user details
	4. dashboard reports
	5. analytics
	6. hospital patient information
	7. banking summaries.

* Cards improve : 
		
	1. UI appearance
	2. readability
	3. responsive design
	4. content organization

What is a Card?

* A card is a flexible Bootstrap container used to group related information together.

* A card may contain : 
	
	1. heading
	2. image
	3. description
	4. buttons
	5. footer
	6. links

* Cards create a professional content box with proper : 
	
	1. spacing
	2. border
	3. padding
	4. alignment

Why Cards Important?

* Before Bootstrap cards, developers manually created :
	
	1. borders
	2. shadows
	3. spacing
	4. layouts

-> This caused : 
	
	1. repeated CSS
	2. inconsistent design
	3. maintenance problems

Real-Time Enterprise Usage
--------------------------
* Cards are heavily used in : 
	
	1. Amazon product pages
	2. Flipkart product listings
	3. employee management systems
	4. admin dashboards
	5. CRM applications
	6. hospital systems
	7. analytics portals

Card Structure
--------------
* A Bootstrap card may contain : 
	
	1. card : Main container
	2. card-header : Top section
	3. card-body : Main content
	4. card-title : Card heading
	5. card-text : Description
	6. card-footer : Bottom section
