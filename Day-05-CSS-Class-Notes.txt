1. CSS Position

* The CSS 'position' property is used to control how HTML elements are palced inside a webpage.
	
* Positioning is widely used in : 
	
	* navigation systems
	* responsive layouts
	* chat applications
	* dashboards
	* e-commerce websites
	* mobile applications

Types of Position
------------------
* CSS provides five major position values : 
	
	1. static : Default browser positioning
	2. relative : Moves relative to original position
	3. absolute : Positioned relative to nearset positioned parent
	4. fixed : Fixed relative to viewport
	5. sticky : Behaves like relative fixed

Example 1 : Relative Position

1. Index.html : 

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS Position Examples</title>
  <link rel="stylesheet" href="style.css">
</head>

<body>
  <div class="box">
    Relative Box
  </div>
</body>

</html>

2. style.css : 

.box{
    width: 200px;
    height: 100px;

    background-color: royalblue;
    color: white;

    position: relative;

    top: 30px;
    left: 50px;
}

Real-Time Usage Case
--------------------
* Relative positioning is used for : 
	
	1. small UI adjustments
	2. badge placement
	3. tooltip anchors
	4. icon alignment
	5. dropdown menu positioning

2. Media Queries In CSS

* Basic Media Query Syntax : @media screen, print, speech and (max-width : 768px){}	

max-width : Apply styles BELOW a specific width.
min-width : Apply styles ABOVE a specific width.

Common Industry Break Points
----------------------------
1. Mobile : 0px - 600px
2. Tablet : 601px - 992px
3. Laptop : 993px - 1200px
4. Desktop : 1201px and above.

Example 1 : Responsive Background Color

1. Index.html : 

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Media Queries Examples</title>
  <link rel="stylesheet" href="style.css">
</head>

<body>
  <div class="container">
    Responsive Background
  </div>
</body>

</html>

2. style.css : 

.container{
    background-color: royalblue;

    color: white;

    padding: 50px;

    font-size: 30px;
}

/* Mobile Devices */

@media screen and (max-width: 600px){
    .container{
        background-color: crimson;
    }
}

Why This Is Important?

* Responsive design allows developers to : 
	
	1. simplify mobile UI
	2. improve readability
	3. optimize layouts for smaller screens

Real-Time Usage Case
--------------------
* Used in : 
	
	1. mobile themes
	2. adaptive branding
	3. dark mode variations
	4. responsive sections

Example 2 : Responsive FlexBox Layout

1. Index.html : 

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Media Queries Examples</title>
  <link rel="stylesheet" href="style.css">
</head>

<body>
  <div class="wrapper">
    <div class="card">Card 1</div>
    <div class="card">Card 2</div>
    <div class="card">Card 3</div>
  </div>
</body>

</html>

2. style.css : 

.wrapper {
    display: flex;

    gap: 20px;
}

.card {
    background-color: orange;

    padding: 40px;

    color: white;
}

/* Mobile Layout */

@media screen and (max-width: 768px) {
    .wrapper {
        flex-direction: column;
    }
}

Why This Is Important?

* Horizontal layouts often become compressed on mobile devices.

* Changing layout direction improves : 
	
	1. readability
	2. spacing
	3. touch accessibility
	4. mobile user experience

Real-Time Usage Case
--------------------
* Used In : 
	
	1. responsive dashboards
	2. mobile navigation menus
	3. product cards
	4. admin panels

2. style.css :

Example 5 : Responsive Grid Layout

1. Index.html : 

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Media Queries Examples</title>
  <link rel="stylesheet" href="style.css">
</head>

<body>
  <div class="grid">
    <div class="item">Item 1</div>
    <div class="item">Item 2</div>
    <div class="item">Item 3</div>
    <div class="item">Item 4</div>
  </div>
</body>

</html>

2. style.css : 

.grid {
    display: grid;

    grid-template-columns: repeat(4, 1fr);

    gap: 20px;
}

.item {
    background-color: royalblue;

    color: white;

    padding: 50px;
}

/* Tablet */
@media screen and (max-width: 900px) {
    .grid {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* Mobile */
@media screen and (max-width: 500px) {
    .grid {
        grid-template-columns: 1fr;
    }
}

Why This is Important?

* Without responsive grids : 
	
	1. cards become to narrow
	2. text overflows
	3. layouts break

Real-Time Usage Case
--------------------
* Used In : 
	
	1. e-commerce websites
	2. image galleries
	3. admin dashboards
	4. analytics panels
