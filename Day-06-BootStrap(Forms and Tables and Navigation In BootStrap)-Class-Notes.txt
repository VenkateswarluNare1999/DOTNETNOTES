Bootstrap Forms
---------------
* Forms are used to collect data from users.

Examples : 
	
	1. Login Form
	2. Registration Form
	3. Employee Form
	4. Payment Form
	5. Contact Form
	6. Search Form
	7. Feedback Form

* All these are created using Forms.

What is a Form?

* A Form is a UI structure used to collect input data from users.

* Users provide information using : 
	
	1. textboxes
	2. checkboxes
	3. radio buttons
	4. dropdowns
	5. password fields
	6. buttons

Why Bootstrap Forms Important?

* Before Bootstrap, developers manually styled : 
	
	1. inputs
	2. labels
	3. dropdowns
	4. checkboxes

* This caused : 
	
	1. inconsistent UI
	2. extra CSS
	3. poor responsiveness

Real-Time Enterprise Usage
--------------------------
* Forms are heavily used in :
	
	1. banking applications
	2. employee portals
	3. hospital management
	4. CRM applications
	5. e-commerce websites
	6. admin dashboards
	
Main Form Classes
-----------------
* Bootstrap provides several important form classes.

	1. form-control : Textbox styling
	2. form-check   : Checkbox / radio container
	3. form-check-input : Checkbox input
	4. form-select : Dropdown styling

Example : 

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Bootstrap Forms</title>

  <!-- Bootstrap CSS -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet"
    integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB" crossorigin="anonymous">

<body>

  <div class="container mt-4">
    <input type="text" placeholder="Enter Name" class="form-control">

    <div class="form-check mt-2">
      <input type="checkbox" class="form-check-input">
      <label for="">Accept Terms</label>
    </div>

    <select name="" id="" class="form-select mt-2">
      <option value="">Select Course</option>

Bootstrap Navbar
-----------------
Navbar means : Navigation Bar

* A navbar is used to provide navigation links in a website or web applications

* It helps users navigate between : 
	
	1. pages
	2. modules
	3. dashboards
	4. menus

Why Navbar Important?

* Without navbar : 
	
	1. users cannot navigate properly
	2. website becomes confusing
	3. user experience becomes poor

* Navbar improves : 
	
	1. navigation
	2. accessibility
	3. usability
	4. responsive design

Basic Navbar Structure
----------------------
* Bootstrap navbar mainly uses : 
	
	1. navbar : Main navbar container
	2. navbar-brand : Website logo / title
	3. navbar-nav : Navigation items container
	4. nav-item : Individual menu item
	5. nav-link : Navigation link

Example : 

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Bootstrap Navbar</title>

  <!-- Bootstrap CSS -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet"
    integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB" crossorigin="anonymous">
</head>

<body>
  <nav class="navbar navbar-expand-lg navbar-dark bg-dark">
    <div class="container-fluid">
      <a href="#" class="navbar-brand">My Website</a>

      <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navbarContent">
        <span class="navbar-toggler-icon"></span>
      </button>

      <div class="collapse navbar-collapse" id="navbarContent">
        <ul class="navbar-nav ms-auto">
          <li class="nav-item">
            <a href="#" class="nav-link active">Home</a>
          </li>
          <li class="nav-item">
            <a href="#" class="nav-link">About</a>
          </li>
          <li class="nav-item">
            <a href="#" class="nav-link">Contact</a>
          </li>
        </ul>
      </div>
    </div>
  </nav>

  <!-- Bootstrap JS -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"
