3. Background Styling

* Background styling controls the visual appearance behind HTML elements.

* CSS allows developers to apply : 
	
	1. colors
	2. images
	3. gradients
	4. positioning
	5. repeat behaviour
	6. background sizing

* Background styling is important, because it creates : 
	
	1. visual identity
	2. branding
	3. readability

* Modern websites heavily use : 
	
	1. gradient backgrounds
	2. hero section images
	3. overlay effects
	4. full-screen banners
	5. animated backgrounds

* Backgrounds are one of the most visually impactful parts of UI design.

<!DOCTYPE html>

5. Transform Effects

* The CSS 'transform' property allows developers to visually modify elements without affecting document flow. 

* Transformations can : 
	
	1. move
	2. rotate
	3. scale
	4. skew
	5. flip elements

* Transforms are heavily used in : 
	
	1. hover effects
	2. sliders
	3. animations
	4. interactive UI components
	5. modern Web applications

Example 1 : Scale Effect

Index.html : 

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Transforms Examples</title>
  <link rel="stylesheet" href="style.css">
</head>

<body>
  <div class="card">
    Hover Me
  </div>
</body>

</html>

style.css : 

.card{
    width: 200px;

    padding: 40px;

    background-color: royalblue;

    color: white;

    transition: 0.3s;
}

.card:hover{
    transform: scale(1.1);
}

6. Transition animations

* Transitions create smooth animated changes between CSS property states.

* Transitions are widely used for : 
	
	1. hover effects
	2. button animations
	3. dropdown menus
	4. modal appearance
	5. smooth UI feedback
	6. naviagation interactions

* A transition defines : 
	
	1. property
	2. duration
	3. timing function
	4. dely

Example 1 : Button Hover Effect

Index.html : 

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Transitions Examples</title>
  <link rel="stylesheet" href="style.css">
</head>

<body>
  <button class="btn">Hover Me</button>
</body>

</html>

style.css : 

.btn{
    background-color: royalblue;

    color: white;

    padding: 15px 30px;

    border: none;

    transition: 0.3s;
}

.btn:hover{
    background-color: red;
}

Example 2 : Card Lift Effect

Index.html : 

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Transitions Examples</title>
  <link rel="stylesheet" href="style.css">
</head>

<body>
 <div class="lift-card">Card Animation</div>
</body>

</html>

style.css : 

.lift-card {
    width: 250px;

    padding: 40px;

    background-color: white;

    box-shadow: 0 4px 10px rgba(0, 0, 0, 0.2);

    transition: 0.4s;
}

.lift-card:hover {
    transform: translateY(-10px);
}
