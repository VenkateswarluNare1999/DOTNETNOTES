Important '<img>' Tag Attributes
--------------------------------

1. src -> Specifies image path or URL
2. alt -> Alternative text for accessibility
3. width -> Sets image width
4. height -> Sets image height
5. title -> Tooltip text
6. loading -> Controls image loading behavior
7. class -> Applies CSS class styling

Division Element (<div>)
------------------------
Definition : 

* The <div> tag element is used to group content into sections, it is a block-level container
* The <div> tag element is a Paired tag

Why use <div> : 

1. Organize content for CSS styling
2. Create layouts (header, Sidebar, Footer, Main Content)
3. Group elements for JavaScript manipulation

1. HTMl Tables
--------------
* In HTML, a table is used to present structured data.

* structured data means information arranged in rows and columns, similar to how data is displayed in Excel sheets.

* In HTML, a table is created using the <table> element.

* Inside the table element, we define different components such as : 
	
	1. Table header
	2. Table body
	3. Table footer
	4. Table rows
	5. Table cells
	
Syntax of Table :

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>
  <table>
    <thead>
      <tr>
        <th></th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td></td>
      </tr>
    </tbody>
    <tfoot>
      <tr>
        <td></td>
      </tr>
    </tfoot>
  </table>
</body>

</html>

1. Table header

* The table header represents the top section of a table

* It usually contains column titles that describe the data inside each column.

* The table header is defined using the 'thead' element

* The purpose of the header is to clearly describe the type of data stored in each column.

Example Structure : 

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>

<body>
  <table>
    <thead>
      <tr>
        <th>Name</th>
        <th>Age</th>
      </tr>
    </thead>
  </table>
</body>

</html>

2. Table body

* The table body represents the main content of the table

* It contains the actual data records

* The table body is defined using the 'tbody' element

Example :
