Bootstrap Modal
---------------

* A modal is a popup window that appears on top of the webpage.

* It is used to display : 
	
	1. forms
	2. alerts
	3. confirmation messages
	4. login screens
	5. detailed information
without moving to another page.

* Modal is a Bootstrap component, It appears above the current page and temporily blocks background interaction untile user close it.

Why Modal Important?

* Without modal : 
	
	1. users navigate to different pages
	2. user experience becomes slow
	3. too many page reloads happen

* Modals improve : 
	
	1. user interaction
	2. speed
	3. experience
	4. responsiveness

Real-Time Enterprise Usage
---------------------------
* Bootstrap modals are heavily used in : 
	
	1. login popups
	2. registration forms
	3. delete confirmations
	4. edit forms
	5. payment confirmation
	6. employee details popup

Example : 

<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Bootstrap Modal</title>

  <!-- Bootstrap CSS -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet"
    integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB" crossorigin="anonymous">

<body>
  <div class="container mt-5">
    <button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#myModal">Open Modal</button>
  </div>

  <div class="modal" id="myModal">
    <div class="modal-dialog">
      <div class="modal-content">

          Welcome to Bootstrap Modal Example
        </div>

        <div class="modal-footer">
          <button class="btn btn-secondary" data-bs-dismiss="modal">Close</button>
          <button class="btn btn-primary">Save</button>
        </div>
      </div>
    </div>
  </div>

</html>

Why Enterprise Applications Use Modals?

* Because modals provide : 
	
	 1. fast interaction
	 2. reduced page reload
	 3. better UX
	 4. responsive popup design
	 5. professional interface
	
Modal Sizes
-----------
* Bootstrap supports : 
	
	1. small modal : <div class="modal-dialog modal-sm"></div>
	2. large modal : <div class="modal-dialog modal-lg"></div>
	3. extra large modal : <div class="modal-dialog modal-xl"></div>
	
Bootstrap Accordian
--------------------
* Accordian is used to expand and collapse content sections.

* Accordian is a collapsible content component

Users can : 
	
	1. click heading
	2. expand content
	3. collapse content

This improves : 
	
	1. readability
	2. space management
	3. user experience

Why Accordian Important?

* Without accordian : 
	
	1. pages become lengthy
	2. too much scrolling required
	3. content becomes difficult to management

Accordian helps : 
	
	1. save screen space
	2. organize information
	3. improves navigation

Real-Time Enterprise Usage
--------------------------

* Bootstrap accordians are heavily used in : 
	
	1. FAQ pages
	2. admin dashboards
	3. reports
	4. employee details
	5. product specifications
	6. banking statements

Bootstrap Carousel	
-------------------

* Carousel is used to display multiple images or content in sliding format.

* Carousel is a slideshow component

* It rotates content such as : 
	
	1. images
	2. banners
	3. promotions
	4. advertisements in a dynamic sliding manner.

Why Carousel Important?

* Without Carousel : 
	
	1. homepage looks static
	2. multiple banners occupy large space
	3. user engagement decreases

* Carousel helps : 
	
	1. display multiple items
	2. save screen space
	3. improve UI attractiveness

Real-Time Enterprise Usage
--------------------------
* Bootstrap Carousel is heavily used in : 
	
	1. e-commerce websites
	2. news portals
	3. banking promotions
	4. hospital announcements
	5. online learning platforms
