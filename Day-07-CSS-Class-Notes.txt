What is Difference Between pixels(px) and Percentage(%)
-------------------------------------------------------

* px -> Fixed amount : is a fixed measurement

* % -> a portion of a reference size

1000 units wide

50%

50% of 1000 = 500

600 units

50%

50% of 600 = 300

500px 

1000px -> 500px
600px -> 500px

Why do we need %
