Bootstrap In Angular
--------------------
* How To Install Bootstrap In Angular

Command : npm install bootstrap.

* How To Adding Bootstrap CSS

Open : angular.json

"styles": [
              "node_modules/bootstrap/dist/css/bootstrap.min.css",
              "src/styles.css"
            ]

app.html :

<div class="container mt-4">
    <h2 class="text-primary mb-4">Employee Registration</h2>

    <form #employeeForm="ngForm" (ngSubmit)="saveEmployee()">
        <div class="mb-3">
            <label for="" class="form-label">Employee Name</label>
            <input type="text" class="form-control" name="employeeName" [(ngModel)]="employee.employeeName" required
                minlength="3" maxlength="50" #employeeName="ngModel">

            @if (employeeName.touched && employeeName.invalid) {
            <div>
                @if (employeeName.errors?.['required']) {
                <small class="text-danger">Employee Name is required.</small>
                }
                @if (employeeName.errors?.['minlength']) {
                <small class="text-danger">Minimum 3 characters required.</small>
                }
            </div>
            }

        </div>

        <div class="mb-3">
            <label for="" class="form-label">Employee Email</label>
            <input type="text" class="form-control" name="email" [(ngModel)]="employee.email" required email
                #email="ngModel">

            @if (email.touched && email.invalid) {
            <div>
                @if (email.errors?.['required']) {
                <small class="text-danger">Please enter a valid Email.</small>
                }
            </div>
            }
        </div>

        <button type="submit" class="btn btn-primary me-2" [disabled]="employeeForm.invalid">Save</button>

        <button type="reset" class="btn btn-secondary">Reset</button>
    </form>
</div>
