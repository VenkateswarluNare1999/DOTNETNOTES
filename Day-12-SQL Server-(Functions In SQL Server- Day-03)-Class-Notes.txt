Aggregate Functions In SQL Server
---------------------------------
* Aggregate functions perform a calculation on multiple rows and return one result for each group.

Example : If a Sales table contains 10, 000 rows, aggregate functions can calculate the total sales, average sales, highest sales, lowest sales, or number of sales.

* The most important SQL Server aggregate functions are : 
	
	1. COUNT()
	2. SUM()
	3. AVG()
	4. MIN()
	5. MAX()

1. COUNT()
	
	* COUNT() returns the number of rows or non-NULL values in a column.
	
	Syntax : COUNT(*) or COUNT(column_name) or COUNT(DISTINCT column_name)
	
	Example 1 : Count all rows -> SELECT COUNT(*) AS TotalEmployees From Employees;
	
	Example 2 : Count non-NULL values -> SELECT COUNT(Email) AS EmployeeWithEmail From Employees;
	
	* Common Use cases : 
		
		1. Number of customers
		2. Number of employees
		3. Number of orders
		4. Number of transactions
		5. Number of products
		6. Record counts in reports

2. SUM()

	* SUM() returns the total of numeric values in a column.
	
	Syntax : SUM(numeric_column);
	
	Example 1 : SELECT SUM(Salary) As TotalSalary FROM Employees;
	
	* Common Use Cases : 
		
		1. Total Sales
		2. Total revenue
		3. Total quantity
		4. Total Salary
		5. Total expenses
		6. Total inventory

3. AVG()
	
	* AVG() returns the average value of a numeric column.
	
	Syntax : AVG(numeric_column);
	
	Example : SELECT AVG(Salary) As AverageSalary FROM Employees;
	
	* Common Use Cases :
		
		1. Average Salary
		2. Average order value
		3. Average Product price
		4. Average customer rating
		5. Average transaction amount
		
4. MIN()
	
	* MIN() returns the smallest value from a column.
	
	Syntax : MIN(expression);
	
	Example : SELECT MIN(Salary) FROM Employees;
	
	* Common Use Cases :
		
		1. Lowest Salary
		2. Minimum Salary
		3. Earliest date
		4. Lowest transaction amount
		5. Minimum stock level
	
5. MAX()
	
	* MAX() returns the largest value from a column.
	
	Syntax : MAX(expression);
	
	Example : SELECT MAX(Salary) FROM Employees;
	
	* Common Use Cases :
		
		1. Highest Salary
		2. Highest Sales amount
		3. Maximum product price
		4. Latest Order
		5. Latest Login
		6. Highest transaction

Question 1 : Count Employees In a IT Department

SELECT COUNT(*) AS ITEmployees From Employees WHERE Department = 'IT';

Question 2 : Find The Number of Employees In Each Department

SELECT Department, COUNT(*) AS EmployeeCount FROM Employees GROUP BY Department;

Question 3 : Find the Average Salary For Each Department

SELECT Department, AVG(Salary) AS AverageSalary FROM Employees GROUP BY Department;

Question 4 : Find the Total Salary For Each Department

SELECT Department, SUM(Salary) AS TotalSalary FROM Employees GROUP BY Department;

Question 5 : Find the Second Highest Salary

SELECT MAX(Salary) AS SecondHighestSalary FROM Employees WHERE Salary < (SELECT MAX(Salary) FROM Employees);

Question 6 : TOP

SELECT TOP 1 Salary From Employees WHERE Salary < (SELECT MAX(Salary) From Employees) ORDER BY Salary DESC;
