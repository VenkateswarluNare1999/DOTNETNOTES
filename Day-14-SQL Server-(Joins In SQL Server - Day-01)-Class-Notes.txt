Joins In SQL Server
--------------------
* A Join is a SQL operation used to combine rows from two or more tables based on a related column between them.

* Joins are performed using Primary key and Foreign key Relationships.

* There are 6 Types of Joins

	1. Inner Join
	2. Left Join
	3. Right Join
	4. Full Join
	5. Cross Join
	6. Self Join

1. Inner Join

* An INNER JOIN returns only the rows where matching values exist in both tables.

* If a row in one table does not have a matching value in the other table, that row will not appear in the result.

Syntax : SELECT column1, column2, column3 From Table1 INNER JOIN Table2 ON Table1.Matching Column = Table2.Matching Column

Example : SELECT e.Name, d.DeptName FROM Employees e INNER JOIN Departments d ON e.DeptId = d.DeptId;

CREATE TABLE Customers
(
	CustomerId Int Primary Key,

(

Question 1 : Display Customers Who have Placed Orders (CustomerName, OrderId, and Amount)

SELECT c.CustomerName, o.OrderId, o.Amount
FROM Customers c
INNER JOIN Orders o 
ON c.CustomerId = o.CustomerId;

Question 2 : Display Customer Name and Order Date (Customer Name, Order Id, Order Date)

SELECT c.CustomerName, o.OrderId, o.OrderDate
FROM Customers c
INNER JOIN Orders o 
ON c.CustomerId = o.CustomerId;

Question 3 : Find Customers From Hyderabad Who Placed Orders

SELECT c.CustomerName, c.City, o.OrderId, o.OrderDate
FROM Customers c
INNER JOIN Orders o 
ON c.CustomerId = o.CustomerId WHERE c.City = 'Hyderabad';

Question 4 : Display Customer Name, Order Id, Product Name, Quantity

SELECT c.CustomerName, o.OrderId, p.ProductName, od.Quantity
FROM Customers c
INNER JOIN Orders o 
ON c.CustomerId = o.CustomerId
INNER JOIN OrderDetails od ON o.OrderId = od.OrderId
INNER JOIN Products p
ON od.ProductId = p.ProductId;

Question 5 : Find All Products Ordered by Rahul

SELECT c.CustomerName, o.OrderId, p.ProductName, od.Quantity
FROM Customers c
INNER JOIN Orders o 
ON c.CustomerId = o.CustomerId
INNER JOIN OrderDetails od ON o.OrderId = od.OrderId
INNER JOIN Products p
ON od.ProductId = p.ProductId WHERE c.CustomerName = 'Rahul';
