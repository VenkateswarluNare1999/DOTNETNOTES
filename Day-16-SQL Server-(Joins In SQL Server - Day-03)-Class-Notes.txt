RIGHT JOIN In SQL Server
------------------------
* RIGHT JOIN works exactly opposite to LEFT JOIN.

* A RIGHT JOIN returns all rows from the right table and matching rows from the left table.

* If no matching rows exists in the left table, SQL Server fills those columns with NULL.

Example :

CREATE TABLE Employees
(
	EmployeeId Int PRIMARY KEY,
	EmployeeName varchar(50),
	DepartmentId Int,
	Salary decimal(10,2)
);

CREATE TABLE Departments
(
	DepartmentId Int PRIMARY KEY,
	DepartmentName varchar(50)
);

Question 1 : Display all departments and their employees, including departments that don't have any employees.

SELECT d.DepartmentId,
		d.DepartmentName,
		e.EmployeeId,
		e.EmployeeName
FROM Employees e
RIGHT JOIN Departments d
	ON e.DepartmentId = d.DepartmentId;
	
Question 2 : Display department name and employee name for all departments.

SELECT d.DepartmentName,
		e.EmployeeName
FROM Employees e
RIGHT JOIN Departments d
	ON e.DepartmentId = d.DepartmentId;

Question 3 : Find departments that currently have no employees

SELECT  d.DepartmentId,
		d.DepartmentName
FROM Employees e
RIGHT JOIN Departments d
	ON e.DepartmentId = d.DepartmentId
WHERE e.EmployeeId IS NULL;

Question 4 : Display all departments and their employees, sorted by department name

SELECT  d.DepartmentName,
		e.EmployeeName
FROM Employees e
RIGHT JOIN Departments d
	ON e.DepartmentId = d.DepartmentId
ORDER BY d.DepartmentName;

Question 5 : Display all departments and employees salaries, If a department has no employee, show NULL for salaries.

SELECT  d.DepartmentName,
		e.EmployeeName,
		e.Salary
FROM Employees e
RIGHT JOIN Departments d
	ON e.DepartmentId = d.DepartmentId;

FULL JOIN In SQL Server
------------------------	
* A FULL JOIN returns all rows from both tables.

* If rows match, they are combined.

* If rows do not match, NULL values appear in the missing columns.

* FULL JOIN is the combination of LEFT JOIN and RIGHT JOIN.

Example :

Question 1 : Display all employees and all departments

SELECT 
	e.EmployeeId,
	e.EmployeeName,
	e.DepartmentId,
	d.DepartmentName
FROM Employees e
FULL JOIN Departments d
	ON e.DepartmentId = d.DepartmentId;
	
Question 2 : Display employee name and department name

SELECT 
	e.EmployeeName,
	d.DepartmentName
FROM Employees e
FULL JOIN Departments d
	ON e.DepartmentId = d.DepartmentId;

Question 3 : Find employees who don't have a matching department

SELECT 
	e.EmployeeId,
	e.EmployeeName,
	e.DepartmentId
FROM Employees e
FULL JOIN Departments d
	ON e.DepartmentId = d.DepartmentId
WHERE d.DepartmentId IS NULL;

Question 4 : Find departments that don't have any employees

SELECT 
	d.DepartmentId,
	d.DepartmentName
FROM Employees e
FULL JOIN Departments d
	ON e.DepartmentId = d.DepartmentId
WHERE e.EmployeeId IS NULL;

Question 5 : Display all employees and departments sorted by Department Id	

SELECT 
	e.EmployeeId,
	e.EmployeeName,
	e.DepartmentId AS EmployeeDepartmentId,
	d.DepartmentId AS DepartmentTableId,
	d.DepartmentName
FROM Employees e
FULL JOIN Departments d
	ON e.DepartmentId = d.DepartmentId
ORDER BY d.DepartmentId;
