CROSS JOIN In SQL Server
------------------------

* A CROSS JOIN produces the Cartesian Product of two tables, This means every row of the first table is combined with every row of the second table.

Syntax : SELECT * FROM Table1 CROSS JOIN Table2

Example :

CREATE TABLE Products
(
	ProductId Int,
	ProductName varchar(50),
	Price decimal(10,2)
);

INSERT INTO Products VALUES
(1, 'Laptop', 60000),
(2, 'Mouse', 1000),
(3, 'Keyboard', 2000);

CREATE TABLE Colors
(
	ColorId Int,
	ColorName varchar(30)
);

INSERT INTO Colors VALUES
(1, 'Black'),
(2, 'White'),
(3, 'Blue');

CREATE TABLE SIzes
(
	SizeId Int,
	SizeName varchar(20)
);

INSERT INTO SIzes VALUES
(1, 'Small'),
(2, 'Medium'),
(3, 'Large');

Question 1 : Display every possible combination of products and colors.

SELECT
	p.ProductName,
	c.ColorName
FROM Products p
CROSS JOIN Colors c

Question 2 : Display every possible combination of products and sizes

SELECT
	p.ProductName,
	s.SizeName
FROM Products p
CROSS JOIN SIzes s

Question 3 : Generate every possible combination of product, color, and size

SELECT
	p.ProductName,
	c.ColorName,
	s.SizeName
FROM Products p
CROSS JOIN Colors c
CROSS JOIN SIzes s

Question 4 : Display product name, price, and every available color.

SELECT
	p.ProductName,
	p.Price,
	c.ColorName
FROM Products p
CROSS JOIN Colors c;

Question 5 : Display only combinations where the color is Black

SELECT
	p.ProductName,
	c.ColorName
FROM Products p
CROSS JOIN Colors c
WHERE c.ColorName = 'Black';

SELF JOIN In SQL Server
------------------------
* A SELF JOIN occurs when a table is joined with itself, this is commonly used to represent hierarchical relationships such as :
	
	1. Employee -> Manager
	2. Category -> Parent Category

Syntax :

SELECT
	A.ColumnName,
	B.ColumnName
FROM TableName A	
INNER JOIN TableName B
	ON A.SomeColumn = B.SomeColumn;
	
CREATE TABLE Employees

Question 1 : Display each employee's name along with their manager's name.

SELECT
	E.Name AS Employee,
	M.Name AS Manager
FROM Employees E
INNER JOIN Employees M
	ON E.ManagerId = M.Id

Question 2 : Display employee name, employee job title, manager name, and manager job title.

SELECT
	E.Name AS Employee,
	E.JobTitle AS EmployeeJobTitle,
	M.Name AS Manager,
	M.JobTitle AS ManagerJobTitle
FROM Employees E
INNER JOIN Employees M
	ON E.ManagerId = M.Id;
