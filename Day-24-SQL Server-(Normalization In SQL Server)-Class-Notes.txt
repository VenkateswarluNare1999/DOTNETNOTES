Normalization In SQL Server
---------------------------
* Normalization is the process of organizing data into related tables to reduce unnecessary duplication and prevent data anomalies.

Why Do We Need Normalization?

1. Data redudancy. Redudancy means storing the same information repeatedly.

2. Update anomaly

3. Insertion anomaly

4. Deletion anomaly

Understanding an Unnormalized Table?

Example :

StudentId : 101, 102, 103

StudentName : Rahul, Priya, Ravi

Course 1 : C#, C#, SQL Server

Course 2 : SQL Server, NULL, Angular

Course 3 : Angular, NULL, NULL

Example :

StudentId : 101, 101, 101, 101, 102, 103, 103

StudentName : Rahul, Rahul, Rahul, Priya, Ravi, Ravi

Course : C#, SQL Server, Angular, C#, SQL Server, Angular

1. First Normal Form - 1NF

* First Normal Form requires that each column contain a single value for each row, with no repeating groups of attributes.

Example : Consider this table

StudentId : 101, 102

StudentName : Rahul, Priya

PhoneNumbers : 9876543210, 9123456780, 9988776655

Example : Individual rows 

StudentId : 101, 101, 102

StudentName : Rahul, Rahul, Priya

PhoneNumbers : 9876543210, 9123456780, 9988776655

Example :

CREATE TABLE StudentPhones
(
	StudentId Int NOT NULL,
	StudentName varchar(100) NOT NULL,
	PhoneNumber varchar(15) NOT NULL,
	CONSTRAINT PK_StudentPhones
		PRIMARY KEY(StudentId, PhoneNumber)
);

INSERT INTO StudentPhones(StudentId, StudentName, PhoneNumber)
VALUES
	(101, 'Rahul', '9876543210'),
	(101, 'Rahul', '9123456780'),
	(102, 'Priya', '9988776655');

SELECT * FROM StudentPhones;

2. Second Normal Form - 2NF

Example :

StudentId : 101, 101, 102

CourseId : C01, C02, C01

StudentName : Rahul, Rahul, Priya

CourseName : C#, SQL Server, C#

Marks : 85, 90, 88

Example :

CREATE TABLE Students
(
	StudentId Int PRIMARY KEY,
	StudentName varchar(100) NOT NULL
);

CREATE TABLE Courses
(
	CourseId varchar(10) PRIMARY KEY,
	CourseName varchar(100) NOT NULL
);

CREATE TABLE Enrollments
(
	StudentId Int NOT NULL,
	CourseId varchar(10) NOT NULL,
	Marks Int NOT NULL,

	CONSTRAINT PK_Enrollments PRIMARY KEY(StudentId, CourseId),
	CONSTRAINT FK_Enrollments_Students FOREIGN KEY(StudentId) REFERENCES Students(StudentId),
	CONSTRAINT FK_Enrollments_Courses FOREIGN KEY(CourseId) REFERENCES Courses(CourseId)
);

INSERT INTO Students(StudentId, StudentName) VALUES(101, 'Rahul'),(102, 'Priya');

INSERT INTO Courses(CourseId, CourseName) VALUES('C01', 'C#'),('C02', 'SQL Server');

INSERT INTO Enrollments(StudentId, CourseId, Marks) VALUES(101, 'C01', 85),(101, 'C02', 90),(102, 'C01',88);

SELECT
	s.StudentId,
	s.StudentName,
	c.CourseId,
	c.CourseName,
	e.Marks
FROM Enrollments AS e
INNER JOIN Students AS s
	ON e.StudentId = s.StudentId
INNER JOIN Courses AS c
	ON e.CourseId = c.CourseId;
	
3. Third Normal Form - 3NF	

Example :

EmpId : 1, 2, 3

EmpName : Rahul, Priya, Ravi

DepId : D01, D02, D01

DeptName : IT, HR, IT

Example :

CREATE TABLE Departments
(
	DeptId varchar(10) PRIMARY KEY,
	DeptName varchar(100) NOT NULL
);

CREATE TABLE Employee
(
	EmpId Int PRIMARY KEY,
	EMpName varchar(100) NOT NULL,
	DeptId varchar(10) NOT NULL,

	CONSTRAINT FK_Employees_Departments FOREIGN KEY(DeptId) REFERENCES Departments(DeptId)
);

INSERT INTO Departments(DeptId, DeptName) VALUES('D01', 'IT'), ('D02', 'HR');

INSERT INTO Employee(EmpId, EMpName, DeptId) VALUES(1, 'Rahul', 'D01'), (2, 'Priya', 'D02'), (3, 'Ravi', 'D01');

SELECT 
	e.EmpId,
	e.EmpName,
	d.DeptId,
	d.DeptName
FROM Employee AS e
INNER JOIN Departments AS d
	ON e.DeptId = d.DeptId;
