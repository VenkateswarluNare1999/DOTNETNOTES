Exception Handling In C#
------------------------
* An exception is an abnormal condition that interrupts normal program execution.

For Example : 

	1. dividing by zero
	2. file not found
	3. database connection failure
	4. network timeout
	5. invalid user input
	6. null reference access

Exception Handling allows application to : 
	
	1. detect errors
	2. handle errors safely
	3. continue meangful messages
	4. maintain application stability

Without exception handling : 
	
	1. applications terminate unexpectedly
	2. users lose data
	3. transactions fail
	4. systems become unstable

* Modern enterprise systems heavily depend on exception handling because production applications continuosly interact with : 
	
	1. databases
	2. APIs
	3. files
	4. cloud services
	5. user inputs
	6. external systems

Structure of Exception Handling
-------------------------------
try
{
	// code block
}
catch
{
	// error code block
}
finally
{
	// success code block	
}	

1. Try block contains risky code that may generate exception.

Example : 
	
	1. file access
	2. division
	3. database operations
	4. API communication

2. Catch block handles exception, If exception occurs inside try block, execution immediately jumps to catch block.

3. Finally block always executes

Whether : exception occurs or exception does not occurs, finally blo' always runs.

Usually used for : 
	
	1. closing database connections
	2. releasing files
	3. cleanup operations

Example : 

namespace TryCatchFinallyBlocks
{
    class Program
    {
        static void Main(string[] args)
        {
			try
			{
                Console.WriteLine("Application Started.");

                Console.Write("Enter First Number : ");
                int num1 = Convert.ToInt32(Console.ReadLine());

                Console.Write("Enter Second Number : ");
                int num2 = Convert.ToInt32(Console.ReadLine());

                int result = num1 / num2;

                Console.WriteLine("Result : " + result);
            }
			catch (DivideByZeroException ex)
			{
                Console.WriteLine("Cannot divide by zero.");
                Console.WriteLine(ex.Message);
			}
            catch (FormatException ex)
            {
                Console.WriteLine("Invalid Input");
                Console.WriteLine(ex.Message);
            }
            finally
            {
                Console.WriteLine("Application Finished.");
            }
        }
    }
}

Complete Exception Flow : try block starts -> Exception occurs ? Yes -> Matching catch executes -> finally executes -> Program continues.

Example : 

namespace TryCatchFinallyBlocks
{
    class Program
    {
        static void Main(string[] args)
        {
            try
            {
                Console.Write("Enter Your Name : ");
                string name = Console.ReadLine();

                Console.Write("Enter Your Age : ");
                int age = Convert.ToInt32(Console.ReadLine());

                if (age >= 18)
                {
                    Console.WriteLine(name + " is an adult.");
                }
                else
                {
                    Console.WriteLine(name + " is a minor.");
                }

                Console.WriteLine("\nNumbers from 1 to 5 : ");

                for (int i = 1; i <= 5; i++)
                {
                    Console.WriteLine(i);
                }

                Console.WriteLine("\nChoose an option : ");
                Console.WriteLine("1. Hello");
                Console.WriteLine("2. Bye");

                int choice = Convert.ToInt32(Console.ReadLine());

                switch (choice)
                {
                    case 1:
                        Console.WriteLine("Hello " + name);
                        break;
                    case 2:
                        Console.WriteLine("Bye " + name);
                        break;
                    default:
                        Console.WriteLine("Invalid choice");
                        break;
                }
            }
            catch (Exception)
            {
                Console.WriteLine("Please enter valid input.");
            }
        }
    }
}
