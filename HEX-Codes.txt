### Example in CSS

body {
  background-color: #F0F8FF;
  color: #000000;
}

button {
  background-color: #4169E1;
  color: #FFFFFF;
}

Note: CSS also supports millions of colors beyond these named colors using HEX values such as #3498DB, #FF5733, etc. A 6-digit HEX code follows #RRGGBB, where RR, GG, and BB represent red, green, and blue.

Quick CSS gradient examples
----------------------------

/* Blue gradient */
background: linear-gradient(135deg, #00C6FF, #0072FF);

/* Purple gradient */
background: linear-gradient(135deg, #8A2BE2, #FF1493);

/* Sunset */
background: linear-gradient(135deg, #FF512F, #F09819);

/* Ocean */
background: linear-gradient(135deg, #2193B0, #6DD5ED);

/* Green */
background: linear-gradient(135deg, #11998E, #38EF7D);

/* Dark */
background: linear-gradient(135deg, #232526, #414345);

If you're learning CSS, the most important format to remember is:

#RRGGBB : 

* RR = Red
* GG = Green
* BB = Blue

For example, #FF0000 = maximum red + no green + no blue = **red**.
